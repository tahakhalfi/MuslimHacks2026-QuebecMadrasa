# Branding — logo officiel

Le logo officiel du site est `public/ui/logo-madrasa-quebec.png`.

Il doit être utilisé dans la landing publique, le footer, la sidebar parent et la sidebar élève. Il ne faut pas le remplacer par un texte ou une icône générique. Sur les fonds sombres, il doit être placé dans un conteneur clair afin de préserver son contraste.
